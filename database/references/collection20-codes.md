## 三、电量字段命名规律（写电量 SQL 的核心规则）

```
方向前缀 × 数据种类 × 费率后缀
```

| 方向前缀 | 含义 |
|---------|------|
| PAP | 正向有功 |
| PRP | 正向无功 |
| RAP | 反向有功 |
| RRP | 反向无功 |

| 数据种类后缀 | 含义 |
|-------------|------|
| _R | 示值（当前/止码） |
| _R_S | 示值（上次/起码） |
| _E | 电能量 |
| _D 或 DEMAND | 最大需量（_TIME 为发生时间） |

| 费率后缀 | 含义 |
|---------|------|
| 无后缀 | 总 |
| R1/E1 | 费率1（尖） |
| R2/E2 | 费率2（峰） |
| R3/E3 | 费率3（平） |
| R4/E4 | 费率4（谷） |
| R5/E5 / R6/E6 | 费率5 / 费率6 |

**示例字段**：
- `PAP_R` 正向有功总示值、`PAP_E1` 尖峰电量、`RAP_R3_S` 反向有功费率3上次示值
- `PAP_DEMAND` / `PAP_DEMAND_TIME` 正向有功总最大需量及发生时间
- `PAP_E_SRC` 电量来源标识（01正常 其他为替代值来源）
- `COMP_RTO` 综合倍率 = 电能表自身倍率 × 电流互感器倍率

**电量计算**：日电量 = 本次示值(止码) − 上次示值(起码)，再乘综合倍率 COMP_RTO（表计直接出 E 字段时直接用）。
